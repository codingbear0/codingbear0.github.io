> [!quote]
> A "Hello, World!" program is usually a simple computer program that emits (or displays) to the screen (often the console) a message similar to "Hello, World!"

대부분의 프로그래밍 언어에서 제일 먼저 작성하는 예제 프로그램으로 단순하게 화면에 “Hello, World!”[^1][^2] 메시지를 표시하는 것 이외에 다른 기능은 없다. 


[^1]: 다양한 변형이 존재. “Hello, world”, “hello, world” 등.
[^2]: 이런 전통?의 기원이  [The C Programming Language]에서는 소문자로만 된 “hello, world” 사용.

## [Practical Common Lisp]
> [!quote]
> The venerable “hello, world” predates even the classic Kernighan and Ritchie C book that played a big role in its popularization. The original “hello, world” seems to have come from Brian Kernighan’s “A Tutorial Introduction to the Language B” that was part of the Bell Laboratories Computing Science Technical Report #8: The Programming Language B published in January 1973. 

- “hello, world”는 [Brian Kernighan]이 [[/sandbox/a-tutorial-introduction-to-the-language-b|A Tutorial Introduction to the Language B]]에서 처음 사용했다고 언급.
